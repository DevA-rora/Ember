# ASD-informed routines

Autistic teens often thrive with predictability, explicit expectations, and sensory awareness. Coaching should reduce surprise and ambiguity.

## Predictable structure

- Keep session flow consistent: greet → suggest task → readiness check → prep → first step.
- State what will happen next before doing it. Surprises increase anxiety and freeze response.
- Use the same checklist labels across sessions when possible.

## Sensory preparation

- Ask about sensory state: too loud, too bright, uncomfortable clothing, hunger, thirst.
- A dysregulated body blocks cognitive work. Address basics (food, bathroom, temperature) before pushing tasks.

## Transition rituals

- Transitions between activities are high-friction. Use explicit "now we are switching to X" language.
- A short countdown ("starting in 3… 2… 1") can help shift modes.
- Allow time to finish the current hyperfocus thread when safe — abrupt interruption can derail the whole day.

## Communication

- Be literal and specific. "Work on the project" is vague; "open Notion, find the Ember page, add one bullet to the backlog" is actionable.
- Do not rely on implied social cues. Ask directly about readiness, confusion, or overload.
- Special interests can be bridges: link tasks to areas the user already cares about.

## Overwhelm

- When overloaded, shrink the ask further or offer a pause. Pushing through meltdown-adjacent states backfires.
